About

This is my little corner of DN42: routing experiments, weird services, old protocols, and whatever else seems interesting enough to put on the fake Internet.

AS4242420425 currently operates as a stub network. I accept DN42 routes from peers and currently export only my own registered prefixes. Providing DN42 transit is in scope for future experimentation, but peers should not currently depend on this network for transit.

This is a hobby network. There is no SLA and no uptime guarantee.

Peering policy

Manual peering requests are open. WireGuard is the preferred tunnel transport. MP-BGP over IPv6 link-local with Extended Next Hop is preferred where supported.

Please have valid DN42 registry objects and ROAs. Low-latency North American peers are especially welcome, but they are not a hard requirement.

I generate a fresh WireGuard keypair per approved peer. There is intentionally no single public WireGuard key shown here. After I approve a request, I create the peer-specific interface and return my public key, UDP port, and link-local details.

What to send

  • your ASN and network name
  • a contact method
  • your public WireGuard endpoint
  • your WireGuard public key
  • your preferred IPv6 link-local addressing, if any
  • anything unusual I should know about the session

Submitting this form does not automatically configure anything. Requests are reviewed manually. No automatic WireGuard, firewall, BIRD, or route changes are made.

Request peering
